F450 Drone Build
This is a quadcopter drone I built under a $400 budget.

About this project
I built a working drone using pre made parts. I picked all the parts, made sure they work together, wired everything, and planned how it would fly.

What I did
Picked all drone parts within budget
Fixed a compatibility issue (receiver didn’t match flight controller)
Checked that all parts work together
Made and checked a wiring diagram
Estimated flight time using battery and motor specs
Kept total cost under $400 ($391.94)
Flight time
The drone should fly for about 5–6 minutes depending on how it’s flown.
